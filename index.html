程序员必备的 VS Code 插件推荐

发表于2025-11-01更新于2026-05-23

前言

VS Code 是当今最流行的代码编辑器之一。丰富的插件生态是其最大的优势。今天分享几个我日常使用频率最高的插件。

外观与主题

  • One Dark Pro — 经典暗色主题，护眼又好看
  • Material Icon Theme — 给文件图标增加辨识度
  • Prettier — 代码格式化工具，支持多种语言

效率提升

  • GitLens — Git 增强工具，查看代码历史和作者
  • Live Server — 本地开发服务器，支持热更新
  • Auto Rename Tag — 自动同步修改 HTML 标签名
  • Path Intellisense — 文件路径自动补全

语言支持

  • ES7+ React/Redux/React-Native snippets — React 代码片段
  • Python — Python 语言支持
  • Vue - Official — Vue 3 官方插件

其他推荐

  • Markdown All in One — Markdown 写作必备
  • Todo Tree — 高亮显示代码中的 TODO 注释
  • Code Spell Checker — 代码拼写检查

结语

好工具能事半功倍，但也不要陷入配置陷阱。找到适合自己的插件组合，专注于写代码本身才是最重要的。

为什么选择 Hexo

Hexo 是一个快速、简洁且高效的静态博客框架。它使用 Markdown 解析文章，通过主题支持快速生成静态页面，非常适合搭建个人博客。

选择主题

Hexo 有丰富的主题生态。我选择了 Stun 主题，它简洁美观，功能丰富，支持：

  • 响应式设计
  • 暗黑模式
  • 多种代码高亮风格
  • 评论系统集成
  • 搜索功能

部署到 GitHub Pages

  1. 创建名为 username.github.io 的仓库
  2. 安装部署插件：npm install hexo-deployer-git --save
  3. 在 _config.yml 中配置部署信息
  4. 运行 hexo deploy

结语

搭建一个个人博客并不复杂，最重要的是坚持写作。希望这篇指南对你有所帮助！
